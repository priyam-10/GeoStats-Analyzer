# 🌍 Country Data Analysis using Python & Pandas

An interactive data analysis project built using Python and Pandas to explore and analyze country-based datasets. This project performs multiple real-world data analysis operations such as population analysis, democracy score ranking, regional analysis, and political leader insights.

---

## 📌 Project Overview

This project uses a dataset containing information about different countries around the world.  
Using Python and Pandas, the project answers important analytical questions from the dataset.

The main objective of this project is to practice:

- Data Analysis
- Data Filtering
- Sorting
- Aggregation
- Conditional Queries
- Exploratory Data Analysis (EDA)

---

## 🚀 Features

### ✔ Population Analysis
- Find country with highest population
- Find country with least population
- Find capital city of highly populated countries

### ✔ Democracy Analysis
- Top 5 countries with highest democracy score

### ✔ Regional Analysis
- Total number of regions
- Countries in Eastern Europe
- Highest populated country in Africa

### ✔ Political Analysis
- Political leader of 2nd highest populated country
- Count countries with unknown political leaders

### ✔ Country Name Analysis
- Count countries having "Republic" in their full name
